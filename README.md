# Hopf–Cole Cosmology

The Hopf–Cole transform maps Burgers' equation, a nonlinear advection–diffusion equation that forms shocks, onto the linear heat equation. This project is an online text that develops that correspondence from first principles and shows how it underlies the Zel'dovich approximation, the adhesion model, and Lagrangian perturbation theory (LPT) for cosmological structure formation.

The numerical core is a Rust crate (`hcc-core`) compiled to WebAssembly, driving interactive 2D/3D experiments in the browser with WebGPU visualization (falling back to Canvas2D). The text is a Quarto book deployed to GitHub Pages; each chapter embeds live panels (1D Burgers / heat / Hopf–Cole / Hopf–Lax demonstrations, a 1D Zel'dovich universe, LPT order by order) and the last part hosts the full 2D/3D laboratory.

**Live site:** <https://yipihey.github.io/hopf-cole-cosmology/>

## Building locally

Requirements: [Rust](https://rustup.rs) with the `wasm32-unknown-unknown` target, [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/), and [Quarto](https://quarto.org) (1.10 or later).

```sh
rustup target add wasm32-unknown-unknown
make wasm      # build the WASM module into app/pkg/
make api       # Rust API documentation into api/ (the ⟨name⟩ links in the text point into it)
make check     # verify that every provenance link of the chapters resolves
make site      # render the website into _site/
make preview   # live-preview the website
make test      # run the Rust tests
make all       # wasm + site
make kernel    # (optional) Python venv + Jupyter kernel `hcc` for re-executing the chapter figures
```

The chapter code cells are frozen (`_freeze/`), so Python is only needed when editing them; the chapters declare `jupyter: hcc` and `make kernel` creates that kernel with `uv`. For local development serve the rendered site with `python3 scripts/serve.py` (it disables caching so a rebuilt WASM module is picked up).

The WASM module must be served over HTTP (not `file://`), e.g. via `make preview` or `python3 -m http.server -d _site`.

## Repository layout

- `core/` — Rust crate `hcc-core`: FFT grid, Gaussian random fields, $n$-th order LPT (2D/3D) with Einstein–de Sitter or exact flat-ΛCDM growth functions for every term, phase-space-sheet (2D triangles, 3D Kuhn tetrahedra) and CIC densities, Hopf–Cole solvers (Fourier multiplier and log-domain kernel), power spectra and 1-loop SPT/Zel'dovich integrals, 1D Burgers tools; `cargo test --release` runs the validation suite
- `app/` — standalone interactive lab (`index.html`, `js/main.js`, `js/lab/`), its WebGPU compute path for 3D (`js/gpu/`: Stockham FFT, CIC deposit, log-domain Hopf–Cole, spectra; `gpu-test.html` validates it against the WASM), the chapter widgets (`js/widgets.js`), the WebGPU/Canvas2D visualization library (`js/viz/`), CSS; `pkg/` is generated by wasm-pack; copied verbatim into the site
- `chapters/` — Quarto chapter sources, `references.bib`, and the appendices `notation.qmd` and `status.qmd`
- `_extensions/yipihey/quadrant/` — the [quadrant](https://github.com/yipihey/quadrant) Quarto extension (installed with `quarto add yipihey/quadrant`) with the provenance shortcodes `{{< src >}}` (link to the rustdoc of the function that evaluates an equation), `{{< test >}}` (badge linking to the test that verifies a claim) and `{{< lab >}}` (button opening the laboratory in a given state)
- `_brand.yml` — palette shared by the book and the lab (`scripts/brand_to_css.py` generates `app/css/brand.css`)
- `docs/` — the format audit and the report standard (now maintained in the quadrant repository); `.claude/skills/interactive-report/` is the agent skill for working in this format
- `index.qmd`, `_quarto.yml` — site landing page and configuration
- `includes/` — HTML snippets injected into every page
- `notebooks/` — the original lecture notebook on Burgers' equation and the Hopf–Cole transform
- `scripts/` — development helpers: `serve.py` (no-cache dev server), `build_info.py` (git revision into the footer), `brand_to_css.py`, `check_links.py`
- `.github/workflows/publish.yml` — build and deploy to GitHub Pages
